# Legacy (versión Python/Flask)

Esta carpeta contiene la versión original en Python/Flask de ObraPasaLista,
anterior al port a Node.js/Express (v1.2.0, ver `src/`).

Se conserva como referencia histórica y documentación del proceso de
migración, pero **no se mantiene ni se ejecuta**. La versión activa del
proyecto es la de `src/*.js`.
